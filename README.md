# ⚡ Vozduxan Messenger (Web / PWA)

> Скоростной защищенный веб-мессенджер нового поколения: эргономичный современный интерфейс в фирменной оранжевой гамме `#FF7A00`, авторский векторный логотип-вихрь, PWA без системных рамок браузера, гарантированное автоудаление сообщений через 14 дней и «Панель Бога» для создателя @stasochec.

---

## 🍊 Ключевые возможности

- **Фирменный брендинг:**
  - Глубокая неоновая оранжевая палитра (`#FF7A00`, `#FF9500`, `#FF5500`).
  - Авторский векторный SVG-логотип: аэродинамический вихрь и парящее крыло (Vortex Air Stream).
  - Полноценная поддержка светлой и темной графитовой темы.
- **PWA (Progressive Web App):**
  - Мобильный полноэкранный вид без системных рамок браузера.
  - Установка на мобильные устройства в 1 клик.
  - Оффлайн-кеширование ассетов через Service Worker (`vite-plugin-pwa`).
- **Автоудаление сообщений (TTL 14 дней):**
  - Все сообщения живут ровно 14 дней, после чего автоматически очищаются на уровне базы данных.
  - В интерфейсе возле каждого сообщения отображается таймер оставшегося времени жизни.
- **Система привилегий и «Панель Бога» (@stasochec):**
  - Аккаунт с никнеймом `@stasochec` автоматически наделяется правами создателя (`owner`).
  - Бейджи: 👑 Создатель / Бог, 🛡️ Модератор, ⚡ Vozdux++ (анимированная пульсирующая звезда), ✅ Verified (оранжевая галочка) и кастомные титулы.
  - Поиск любого пользователя по `@username` и моментальное переключение ролей/статусов в 1 клик.
  - Глобальное официальное оповещение от создателя во все чаты.
- **Деплой на GitHub Pages:**
  - `HashRouter` исключает ошибки 404 при обновлении страниц.
  - Относительный базовый путь `base: './'`.
  - Автоматический CI/CD workflow `.github/workflows/deploy.yml`.

---

## 🛠 Технологический стек

- **Фронтенд:** React 18, Vite 6, TypeScript
- **Стилизация:** Tailwind CSS, Lucide React, Framer Motion
- **Стейт-менеджмент:** Zustand
- **Бэкенд и Realtime:** Supabase (PostgreSQL, Row Level Security, Realtime, Storage)
- **Деплой:** GitHub Actions + GitHub Pages
