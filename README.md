# 🚀 Vozduxan Messenger (Web / PWA)

> Скоростной защищенный веб-мессенджер нового поколения: эргономика Telegram Web в фирменной оранжевой гамме `#FF7A00`, авторский логотип-вихрь, PWA без рамок браузера, автоудаление сообщений через 14 дней (как в Steam) и панель Создателя «как у Дурова».

---

## 🍊 Ключевые возможности

- **Фирменный брендинг:**
  - Глубокая неоновая оранжевая палитра (`#FF7A00`, `#FF9500`, `#FF5500`).
  - Авторский векторный SVG-логотип: аэродинамический вихрь / воздушный поток, переходящий в диалоговый бабл и крыло «V».
  - Полноценная поддержка светлой и темной темы.
- **PWA (Progressive Web App):**
  - Мобильный полноэкранный вид без системных рамок браузера.
  - Установка на iOS и Android в 1 клик.
  - Оффлайн-кеширование ассетов через Service Worker (`vite-plugin-pwa`).
- **Автоудаление сообщений (TTL 14 дней):**
  - Все сообщения живут ровно 14 дней (как чаты в клиенте Steam), после чего автоматически очищаются.
  - В интерфейсе возле каждого сообщения отображается таймер оставшегося времени жизни.
- **Система привилегий и Панель Создателя («Durov Supreme Admin»):**
  - Первый зарегистрированный аккаунт автоматически становится `owner` («Создатель»).
  - Бейджи: 👑 Создатель, 🛡️ Модератор, ⚡ Vozdux++ (анимированная пульсирующая звезда), ✅ Verified (оранжевая галочка) и кастомные титулы.
  - Поиск любого пользователя по `@username` и моментальное переключение ролей/статусов в 1 клик.
  - Глобальное официальное оповещение от Создателя во все чаты сообщества.
- **Деплой на GitHub Pages:**
  - `HashRouter` исключает ошибки 404 при обновлении страниц.
  - Относительный базовый путь `base: './'`.
  - Автоматический CI/CD workflow `.github/workflows/deploy.yml`.

---

## 🛠 Технологический стек

- **Фронтенд:** React 18, Vite 6, TypeScript
- **Стилизация:** Tailwind CSS, Lucide React, Framer Motion
- **Стейт-менеджмент:** Zustand
- **Бэкенд и Realtime:** Supabase (PostgreSQL, Row Level Security, Realtime, Storage)
- **Деплой:** GitHub Actions + GitHub Pages
